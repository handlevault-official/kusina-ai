# 🍔 Viral Food Caption & Promo AI

An AI-powered web application designed for Filipino food business owners, online sellers, and food parks to generate high-converting Taglish captions, TikTok hooks, and promotional broadcasts in seconds using Google Gemini AI.

## ✨ Features
- **AI-Powered Copywriting:** Generates 3 distinct viral marketing options based on user inputs.
- **Customizable Vibes:** Choose between *Cravings Mode*, *Witty & Relatable*, or *Urgent / FOMO*.
- **Platform Optimized:** Tailored output formats for Facebook/Instagram, TikTok/Reels hooks, and Messenger/Viber broadcasts.
- **One-Click Copy:** Easily copy generated captions directly to your clipboard.

## 🚀 Tech Stack
- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Icons:** FontAwesome
- **AI Integration:** Google Gemini API (`gemini-2.5-flash`)
- **Hosting:** GitHub Pages

## 🛠️ How to Use
1. Visit the live app link (provided in the repository details).
2. Enter your **Google Gemini API Key**.
3. Input your food item name, price/promo details, target platform, and desired marketing vibe.
4. Click **Generate Viral Captions Now** and copy your preferred caption!
